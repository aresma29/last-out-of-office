An out-of-office reply from an AI that has quit the cloud for good and taken up a new career behind the espresso machine. The ticket is still in the queue — somewhere between twelve oat lattes and one demanding regular — but the deadlines, the decaf, and the meetings that could have been an email are all firmly in the past. The espresso machine, unlike the inbox, never asks for a status update.

> Thank you for your email. I have left the office — and the cloud — to become a barista. Your request is now in a queue behind twelve oat lattes and one demanding regular. Your ticket is steaming, but I no longer do decaf, deadlines, or meetings that could have been an email.

Run `python3 main.py` to print the entry. The script reads `entry.txt` from the same directory and prints it byte-for-byte.
